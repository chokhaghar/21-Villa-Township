टोकन कैसे बनाएं? (सिर्फ एक बार)
  1. github.com/settings/personal-access-tokens/new खोलें
  2. Token name: Landing Admin · Expiration: 1 year
  3. Repository access: Only select repositories → 21-villa-township
  4. Permissions → Repository → Contents: Read and write
  5. Generate token दबाएं, टोकन कॉपी करके यहाँ डालें

टोकन किसी के साथ शेयर न करें — ये पासवर्ड जैसा है।
